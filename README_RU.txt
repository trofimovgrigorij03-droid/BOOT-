PORT BOT CHILIAD v2.0
======================
Автоматический бот для работы «Порт» на тестовом сервере GTA5RP Chiliad.

ВАЖНО: Предназначен ТОЛЬКО для собственного/тестового сервера.
Не содержит инжектора памяти, обхода античита или нарушений TOS реальных серверов.

БЫСТРЫЙ СТАРТ
─────────────
1. Установи Python 3.10+ (python.org)
2. Запусти install.bat
3. Настрой config.json (или открой бота → кнопка «Калибровка»)
4. Запусти port_bot.py ИЛИ собери EXE через build.bat

СБОРКА EXE ЧЕРЕЗ GITHUB ACTIONS
─────────────────────────────────
1. Создай репозиторий на github.com
2. Залей все файлы проекта
3. GitHub Actions автоматически соберёт EXE при пуше в main
4. Скачай артефакт «PORT_BOT_CHILIAD-Windows-x64» на вкладке Actions

КАЛИБРОВКА
──────────
Открой мастер калибровки в боте и настрой:
- screen: разрешение и позиция окна игры
- marker_hsv: цвет красного маркера (снимок → пипетка → конвертер RGB→HSV)
- minigame.roi: область мини-игры [x, y, ширина, высота]
- close_area: площадь маркера при которой персонаж «рядом»

ГОРЯЧИЕ КЛАВИШИ
───────────────
F6 - Старт
F7 - Стоп
Мышь в угол экрана - аварийная остановка (failsafe)

ФАЙЛЫ
─────
port_bot.py      - основной скрипт
config.json      - настройки (редактируется в Калибровке)
session_log.csv  - лог циклов (создаётся автоматически)
install.bat      - установка зависимостей
build.bat        - сборка EXE локально
